## 3. 手指模式類別

- [ ] 3.1 設定頁加入「手指模式」，不放 ON／OFF 開關。
- [ ] 3.2 尺寸改為四段，稍後實作，不在這次文件提交裡改程式。段位是小、中、大、特大，預設大。小是上游尺寸。中與大是中間段。特大是 44px 目標。
  - 小：一般按鈕 32px、大按鈕 36px、選單項目高 32px、間距 1px、控制點 8px。
  - 中：一般按鈕 36px、大按鈕 39px、選單項目高 36px、間距 4px、控制點 20px。
  - 大（預設）：一般按鈕 40px、大按鈕 42px、選單項目高 40px、間距 6px、控制點 32px。
  - 特大：一般按鈕與大按鈕 44px、選單項目高至少 44px、間距 8px、控制點 44px。
  - 目前沒有已落地的固定 44px 尺寸程式。若之後出現把按鈕或控制點寫死成 44px 的實作，必須改成依段位取值，不能維持單一 44px。預設段位是大，不是特大。
- [ ] 3.3 三點選單的開關屬 `add-finger-mode`。本變更只固定位置：選單裡只有開關，尺寸段位在本設定頁。
