# Tasks

## 1. Workspace 與新建檔案

- [ ] 1.1 選單加入「Workspace」。裡面可以開啟檔案與新建檔案。畫布本身不再有這兩個動作。
- [ ] 1.2 新建時選擇無限畫布或 slide。slide 的紙張尺寸只有 16:9、4:3、A4 的橫式與直式。尺寸在建立後鎖定。
- [ ] 1.3 slide 的起始頁數最少 1、最多 10，預設 10。無限畫布不選頁數。
- [ ] 1.4 每一頁有自己的背景色。新建檔案使用預設背景色。並輸入檔名。
- [ ] 1.5 有頁面尺寸的檔案是多頁。無限畫布是單頁。用語只用 slide 或 page。

## 2. 換頁列與 page manager

- [ ] 2.1 換頁列放在左下角、縮放百分比旁邊。內容是上一頁、下一頁、新增頁，以及只顯示數字的頁碼下拉。兩端循環。無限畫布沒有換頁列。
- [ ] 2.2 縮放百分比、重做、復原維持現狀。
- [ ] 2.3 page manager 從換頁列打開，依最新指示從右側滑入。裡面可改標題、刪除、調順序、新增，並在縮圖與標題清單之間切換。
- [ ] 2.4 長按換頁列會打開輸入標題的彈出，其中也有刪除頁面。
- [ ] 2.5 勾選（盾牌）的安全／加密資訊改到設定頁的關於。問號（說明）按鈕保留。無限畫布的右下角不放任何東西。
- [ ] 2.6 有外接鍵盤的 iPad 可以換頁、加頁，以及做同類的頁面操作。

## 3. 不做的範圍

- [ ] 3.1 不在這個目標選擇檔案位置，也不做跨頁動畫。
- [ ] 3.2 不加入 iPad 螢幕尺寸。不決定像素或公釐、預設背景色、快捷鍵按鍵，以及 page manager 的左右。
- [ ] 3.3 檔案仍須是原版 Excalidraw 打得開的格式。
