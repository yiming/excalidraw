# Tasks

## 1. Workspace 與新建檔案

- [ ] 1.1 選單加入「Workspace」。裡面可以開啟檔案與新建檔案。畫布本身不再有這兩個動作。
- [ ] 1.2 新建時選擇無限畫布或 slide。slide 再選擇紙張尺寸與起始頁數。新建時選擇背景色並輸入檔名。
- [ ] 1.3 slide 的紙張尺寸在檔案建立後鎖定。有頁面尺寸的檔案是多頁。無限畫布是單頁。

## 2. 畫布控制

- [ ] 2.1 右下角換頁列有上一頁、下一頁、新增頁，以及只顯示數字的頁碼下拉。它取代該位置的勾選（盾牌）按鈕。
- [ ] 2.2 勾選（盾牌）的安全／加密資訊改到設定頁的關於。問號（說明）按鈕保留。左下角的縮放百分比、重做、復原不改。

## 3. 不做的決定

- [ ] 3.1 不在這個目標實作選擇檔案位置。
- [ ] 3.2 跨頁補間、頁面的儲存形狀、紙張的實際寬高，都等待確認問題有答案再寫。不要做成原版 Excalidraw 打不開的檔案，也不要在每一幀更新 scene。
