# Design

## Context

- 這是開發目標第 2 項。設定頁與手指模式的規格在 `add-ipad-settings-page` 與 `add-finger-mode`。
- 這個目標只涵蓋檔案結構。參考不是設計決定。
- 用語只用 slide 或 page。不用 scene。使用者原話：「一檔一頁 slide，不叫 scene，用 slide 或 page」。

## Goals / Non-Goals

**Goals:**

- 選單有「Workspace」，可開啟檔案與新建檔案。畫布上不再做這兩件事。
- 新建時選無限畫布或 slide。slide 再選紙張尺寸與起始頁數，並輸入檔名。
- 紙張尺寸是 16:9、4:3、A4 的橫式與直式。建立後鎖定。
- 起始頁數最少 1、最多 10，預設 10。
- 每一頁各自有背景色。新建檔案用預設背景色。
- 有頁面尺寸的檔案是多頁。無限畫布是單頁，不選頁數，也沒有換頁列。
- 換頁列在左下角、縮放百分比旁邊。上一頁與下一頁在兩端會循環。
- page manager 從換頁列打開。最新指示是從右側滑入。裡面可改標題、刪除、調順序、新增，並切換縮圖或標題清單。
- 長按換頁列可輸入標題，並可刪除頁面。
- 外接鍵盤要有換頁、加頁和同類快捷鍵。
- 盾牌的安全／加密資訊改到設定的關於。問號按鈕保留。無限畫布的右下角不放任何東西。

**Non-Goals:**

- 不在這個目標裡選擇檔案位置。
- 不做跨頁動畫。動畫是下一階段。
- 不把 iPad 螢幕尺寸放進現在的紙張清單。
- 不在這個目標決定縮放以後怎麼處理。縮放百分比現在維持不變。

## 參考

這些只是參考，不是本目標已採用的設計。

- Excalidraw Smart Presentation（https://github.com/excalidraw-smart-presentation/excalidraw-smart-presentation.github.io）。研究筆記：多頁／投影片研究（2026-10-27）。它用 frame 當投影片，跨頁元素用 `customData` 裡的名字配對，頁與頁之間有平滑過渡。平滑過渡不屬於這個目標。
- excalidraw-claymate（https://github.com/dai-shi/excalidraw-claymate）。同一份研究。該研究把一頁叫作 scene。本目標不使用這個詞。
- 上游 PR #12157（https://github.com/excalidraw/excalidraw/pull/12157）。研究筆記：Excalidraw+ 簡報尺寸（2026-10-27）。它的尺寸預設有 16:9、4:3、16:10、tablet、phone，並有直式／橫式切換。本目標的清單只有 16:9、4:3、A4 的橫式與直式。

## 限制

- 不要做出原版 Excalidraw 打不開的檔案格式。

## 下一階段

- 動畫留到下一階段，不在這個目標。
- 下一階段若做動畫，不要在每一幀改寫頁面內容。那會灌爆 undo，並觸發同步與存檔。

## 延後項目

- 開啟、儲存、匯出是否移進 Workspace：先擱置，等看過 Workspace 介面再決定。
- iPad 螢幕尺寸以後再加入紙張清單。現在沒有這一項。
- 縮放之後怎麼處理以後再決定。現在左下角的縮放百分比維持不變。

## 待確認問題

- 16:9、4:3、A4 的橫式與直式，實際像素與公釐沒有給定。
- 「一檔一頁 slide」的儲存意思沒有說死：一個檔案裡的多個 slide／page 要怎麼放。這裡不決定。
- page manager 從左邊還是從右邊滑入。最新的具體指示是從右側滑入，風格與現有右上角滑入面板相同。先前則稱它為左邊 side panel 的 page manager。
- 長按換頁列時，長按的是整列，還是只有頁碼下拉。
- 新建檔案的預設背景色沒有給定。
- 之後新增的頁面是否使用同一個預設背景色，沒有說。
- 外接鍵盤的具體按鍵，以及快捷鍵的完整動作清單，沒有給定。已確定的只有換頁、加頁和同類操作。
- 無限畫布的右下角不放任何東西，問號（說明）按鈕又要保留。問號按鈕目前在右下角。這兩句以哪一句為準，尚未決定。
