# Proposal

## Why

- 開發目標第 2 項是多頁 slide。新建檔案時要能選無限畫布或 slide。

## What Changes

- 選單加入「Workspace」。裡面可以開啟檔案與新建檔案。畫布本身不再有開啟檔案或新建檔案。
- 新建檔案時選擇類型：無限畫布（與現在相同）或 slide（PowerPoint 風格）。
- 選了 slide 之後，從列出的紙張尺寸裡選一個。檔案建立後尺寸鎖定。
- 選擇起始頁數。之後可以加頁或刪頁。
- 選擇背景色。之後可以改。
- 輸入檔名。選擇檔案位置不在這個目標。
- 有頁面尺寸的檔案一律是多頁。無限畫布是單頁。
- 右下角換頁列有上一頁、下一頁、新增頁，以及只顯示頁碼的下拉。它取代該位置現有的勾選（盾牌）按鈕。
- 勾選（盾牌）所代表的安全／加密資訊改到設定頁的關於。問號（說明）按鈕保留。左下角的縮放百分比、重做、復原不改。
- 研究只當參考與限制，不是已決定的設計。見 design.md。

## Capabilities

### New Capabilities

- `multipage-slides`：Workspace、新建檔案時的類型與紙張，以及多頁檔的換頁列。

### Modified Capabilities

- 無。`openspec/specs/` 還沒有已接受的能力規格。

## Impact

- 選單、新建檔案、右下角控制，以及設定頁的關於。
- 不包含選擇檔案位置。
- 不決定跨頁補間，也不決定頁面在檔案裡的表示方式。
