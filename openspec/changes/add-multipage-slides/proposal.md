# Proposal

## Why

- 開發目標第 2 項是多頁 slide。這個目標只涵蓋檔案結構。

## What Changes

- 選單加入「Workspace」。裡面可以開啟檔案與新建檔案。畫布本身不再有開啟檔案或新建檔案。
- 新建檔案時選擇類型：無限畫布（與現在相同）或 slide（PowerPoint 風格）。
- slide 的紙張尺寸是 16:9、4:3、A4，各有橫式與直式。iPad 螢幕尺寸現在不在清單裡。檔案建立後尺寸鎖定。
- slide 的起始頁數最少 1、最多 30，預設 10。之後可以加頁或刪頁。
- 每一頁有自己的背景色，可以各自修改。新建檔案使用預設背景色。
- 輸入檔名。選擇檔案位置不在這個目標。
- 有頁面尺寸的檔案一律是多頁。無限畫布永遠是單頁：不選頁數，也沒有換頁列。
- 換頁列在左下角、縮放百分比旁邊。它有上一頁、下一頁、新增頁，以及只顯示頁碼的下拉。第一頁的上一頁與最後一頁的下一頁會循環。
- 縮放百分比、重做、復原維持現狀。縮放之後怎麼處理，以後再決定。
- 勾選（盾牌）的安全／加密資訊改到設定頁的關於。問號（說明）按鈕保留。無限畫布開啟時，右下角不放任何東西。
- 換頁列可以打開 page manager。依最新指示，它從右側滑入，風格與現有右上角滑入面板相同。裡面可以改標題、刪除、調順序、新增，並在縮圖與標題清單之間切換。
- 長按換頁列會打開輸入標題的彈出，其中也有刪除頁面。
- 有外接鍵盤的 iPad 要有換頁、加頁和同類操作的快捷鍵。
- 用語用 slide 或 page，不用 scene。使用者原話：「一檔一頁 slide，不叫 scene，用 slide 或 page」。
- 跨頁動畫不在這個目標。動畫留到下一階段。

## Capabilities

### New Capabilities

- `multipage-slides`：Workspace、slide 檔的頁面結構，以及換頁列與 page manager。

### Modified Capabilities

- 無。`openspec/specs/` 還沒有已接受的能力規格。

## Impact

- 選單、新建檔案、左下角換頁列、page manager，以及設定頁的關於。
- 不包含選擇檔案位置，也不包含跨頁動畫。
