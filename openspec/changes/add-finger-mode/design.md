# Design

## Context

- 設定頁的外殼、類別與視覺見 `add-ipad-settings-page`。本變更只定義手指模式做什麼，以及開關列的版面。
- 先前的程式把三點選單做成勾選，文案用 `toolBar.penMode`，放大也綁在 `penMode` 與單一尺寸。那已改掉。規格以本檔與 `specs/finger-mode/spec.md` 為準。

## Goals / Non-Goals

**Goals:**

- 手指模式只放大規格列出的介面元素。
- 每一項有自己的小、中、大、特大，預設大。小是該項的上游尺寸。
- 開啟且為觸控時，隱藏快捷鍵提示。
- 三點選單與設定頁的開關列都是：左手指圖示、中「手指模式」、右開／關。沒有勾選、快捷鍵、副標或說明。

**Non-Goals:**

- 不改畫布手勢。畫布手勢維持上游，不在本變更範圍。
- 不加入規格沒有列出的行為或設定。這包含把手掌過濾、筆按下時忽略觸控、自動偵測筆、觸覺回饋，以及其他手勢。
- 不為「隱藏快捷鍵提示」再做一個開關。隱藏是手指模式在觸控時的行為。
- 不在開關列放快捷鍵。這與「觸控時隱藏快捷鍵提示」是兩件事。

## Decisions

- 開關列在兩個地方重複同一種版面：三點「更多工具」，以及設定頁主題與語系下方的手指模式區塊。右側只用既有的 `Switch`。
- 標籤的繁體中文就是「手指模式」，對應 `labels.fingerMode`。不用 `toolBar.penMode`。
- 已知像素沿用既有四段，改成各項自己的值。順序是一般按鈕、大按鈕、選單項目高度、選單項目間距、縮放控制點：
  - 小：32 / 36 / 32 / 1 / 8
  - 中：36 / 39 / 36 / 4 / 20
  - 大（預設）：40 / 42 / 40 / 6 / 32
  - 特大：44 / 44 / 至少 44 / 8 / 44
- 第五欄是縮放控制點，也是旋轉控制點的像素。旋轉控制點另有自己的選擇，預設大。
- 某一項選小，或手指模式為關時，該項用上游尺寸。關的時候不套用中、大、特大。開的時候就套用，不限觸控，也不看 `penMode`。
- 手指模式寫入自己的 `fingerMode` 與各項段位，`{ browser: true, export: false, server: false }`。不寫進 `penMode`。
- 設定頁上的選擇器是 `RadioGroup`。開關在各尺寸選擇之上。這條視覺規則的其餘部分在 `add-ipad-settings-page`。
- 畫布手勢改回上游。刪除單指平移、筆按下時忽略手指，以及對捏合縮放的改動。上游 `penMode` 與其按鈕保留。

## Risks / Trade-offs

- 放大在開關為開時就生效，包含滑鼠。觸控才隱藏快捷鍵提示。這是兩個條件。
- 旋轉控制點選小是 8px，與上游滑鼠控制點相同。觸控時上游原本是 28px；手指模式開著並選小時，用規格的 8px。
