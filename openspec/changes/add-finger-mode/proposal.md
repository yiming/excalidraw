# Proposal

## Why

iPad 教學白板用 Apple Pencil 畫、用手指移動畫面。上游在筆模式裡仍讓手指操作選取、套索、文字與圖片，單指又不能平移，自由畫筆時雙指還被鎖成只能平移。手掌或手指先碰到螢幕時，筆會卡住或筆畫被打斷。這些都是上課時會一直碰到的操作，不是新的繪圖功能。

## What Changes

- 沿用第一次 `pointerType === "pen"` 就打開 `penMode`／`penDetected` 的行為。
- 筆模式開啟時，手指在所有工具上都只平移與縮放畫布，包含選取、套索、文字與圖片。
- 筆模式下一根手指平移畫布。
- 筆模式下兩根手指恢復捏合縮放，包含自由畫筆。筆還按在畫布上時不因為手掌而縮放。
- 在三點「更多工具」選單裡加上筆模式開關，跟雷射筆、畫框放在一起。開關要看得出開或關，並適合手指點。
- 筆與手指同時碰到螢幕時，筆不能卡在平移／縮放，進行中的筆畫也不能被手掌打斷。筆模式關閉時，第二根手指仍中止過短的自由畫筆。
- 滑鼠，以及筆模式關閉時的觸控，維持現狀。

## Capabilities

### New Capabilities

- `pen-mode-input`: 筆模式如何區分筆、手指與滑鼠，以及同時碰到螢幕時畫布與筆畫要怎麼反應。

### Modified Capabilities

- 無。`openspec/specs/` 還沒有已接受的能力規格。

## Impact

- 編輯器指標處理（`packages/excalidraw` 的畫布 pointer 與平移工作階段）。
- 桌面／平板工具列與手機工具列的「更多工具」選單。
- 既有 `penMode` 與 `penDetected`。不新增平行的模式狀態，也不改場景檔格式。
- 筆模式使用者會感覺到行為改變：手指不再拖動物件，改為移動畫面。筆模式關閉與滑鼠不受影響。
