# Proposal

## Why

- iPad 上的按鈕、選單列與控制點用手指不好點。
- 手指模式只處理這件事，加上在觸控時隱藏快捷鍵提示。

## What Changes

- 手指模式開啟時，只放大這些介面元素，每一項各自選擇小、中、大、特大，預設是大，小是上游原本尺寸：
  - 一般按鈕
  - 大按鈕
  - 選單項目高度
  - 選單項目間距
  - 縮放控制點
  - 旋轉控制點（獨立一項；像素與縮放控制點相同：小 8、中 20、大 32、特大 44）
- 手指模式開啟且為觸控時，隱藏快捷鍵提示。這不是開關列右側的快捷鍵，也不另做一個設定項。
- 三點「更多工具」選單與設定頁各有一列手指模式開關，版面相同：
  - 左：手指圖示，沒有勾選。
  - 中：標籤只有「手指模式」。
  - 右：只有 `Switch`。
  - 除此之外沒有快捷鍵、副標或說明。
- 尺寸選項在設定頁，主題與語系那一頁的下方。頁面結構見 `add-ipad-settings-page`。

## Capabilities

### New Capabilities

- `finger-mode`：手指模式放大哪些介面元素、各項尺寸，以及開關列長什麼樣子。

### Modified Capabilities

- 無。`openspec/specs/` 還沒有已接受的能力規格。

## Impact

- 三點選單與設定頁的手指模式列。
- 按鈕、選單項目、縮放控制點、旋轉控制點的尺寸，以及觸控時的快捷鍵提示。
- 不改畫布手勢。單指平移、筆按下時忽略手指、對捏合縮放的改動都移除，指標、筆與觸控回到上游。上游 `penMode` 保留。手指模式是獨立設定，開啟就放大，不限觸控。
