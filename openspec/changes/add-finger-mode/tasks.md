# Tasks

## 1. 開關列

- [ ] 1.1 三點「更多工具」與設定頁各放一列，版面相同：左手指圖示、中「手指模式」、右 `Switch` 或「開」「關」。沒有勾選、沒有快捷鍵、沒有副標或說明。
- [ ] 1.2 標籤用 `labels.fingerMode`。不用 `toolBar.penMode`。

## 2. 各項尺寸

- [ ] 2.1 一般按鈕、大按鈕、選單項目高度、選單項目間距、縮放控制點各自有小、中、大、特大，預設大。像素見 `specs/finger-mode/spec.md`。
- [ ] 2.2 旋轉控制點是另一項，也有自己的四段，預設大。中、大、特大的像素等 Open questions 有答案再寫。
- [ ] 2.3 手指模式為關，或該項選小時，該項維持上游尺寸。改一項不會改到其他項。

## 3. 快捷鍵提示

- [ ] 3.1 手指模式開啟且為觸控時，隱藏快捷鍵提示。不另做「隱藏快捷鍵提示」的設定項。開關列本身也不顯示快捷鍵。
