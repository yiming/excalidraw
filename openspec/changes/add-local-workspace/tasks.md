# Tasks

## 1. 本地 Workspace

- [ ] 1.1 選單的 Workspace 可開啟檔案與新建檔案。畫布不再提供這兩個動作，與 `add-multipage-slides` 相同。
- [ ] 1.2 新建時選無限畫布或 slide。slide 的紙張尺寸、頁數、背景色與檔名只引用該規格。
- [ ] 1.3 檔案存在瀏覽器本地。不接 Google Drive，也不做「移到 Drive」。

## 2. 上限

- [ ] 2.1 本地是兩個檔案，每個檔案最多 10 頁，計入的頁數合計最多 20 頁。無限畫布的頁暫時不計入這 20 頁，以後再審查。無限畫布不計入兩個檔案的上限。已滿時提示刪除或匯出。
- [ ] 2.2 不決定 localStorage 或 IndexedDB、已滿提示是否擋住動作。
