# REA 使用規範

[REA](https://github.com/morluto/rea)（Reverse Engineer Anything）是 MIT 授權的 MCP／CLI，用來檢查二進位檔、JS／Electron 應用、.NET 組件與網站。用 REA 或同樣的概念研究其他軟體（包含 Excalidraw+）時，遵守下面的界線。

本規範對齊 REA 在其 [DISCLAIMER.md](https://github.com/morluto/rea/blob/main/DISCLAIMER.md) 所寫的可接受使用範圍；使用者仍須自行遵守法律與授權，本文不是法律意見。

## 可以

- 觀察 UI 與互動流程，記錄行為，理解概念。
- 將 REA 用於正當的研究、教育、互操作性，以及分析我們有權檢視的軟體。

## 不可以

- 反組譯或抽出專有程式碼、演算法，以便再使用。
- 破解 DRM、授權檢查或反作弊。
- 複製他人的程式碼或素材。

## 必須自己重寫

學到的做法要用我們自己的程式從頭實作。REA 的輸出只是靈感，不是可以貼上的來源。

## 每次都要留下紀錄

每一次 REA 工作階段都寫進 `journal/`，註明日期、對象軟體、學到什麼，以及證據。

## 不確定就停

有疑問就先停下來問，得到答覆再繼續。
