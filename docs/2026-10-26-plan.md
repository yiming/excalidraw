## 短期

優先順序：

- 第一：iPad 風格設定頁。紀錄在 `openspec/changes/add-ipad-settings-page/`。外殼用 Modal 加 Dialog，左上角是返回，不是 Close，也不是清單項目。沒有單一選項子頁：主題與語系在同一頁，手指模式的選項在它們下面。設定有「關於」區段。視覺沿用 Excalidraw 的 token 與元件（Island 所在的變數、Dialog、Switch、RadioGroup、`.dropdown-menu-item`）。左側有一個項目，標籤原樣為 Special Thanks To。Excalidraw+、GitHub、追蹤我們、Discord、Sign up 只放在這一頁，是搬移，不是刪除。它們離開漢堡選單與右上角宣傳列。這一頁另有一句感謝 Excalidraw 原作者的文字，不另加 GitHub 網址。新字串要有 zh-TW 與 zh-CN 譯文，鍵名寫在該變更的規格裡。
- 第二：多頁 slide。紀錄在 `openspec/changes/add-multipage-slides/`。範圍只限該規格列出的項目。
- 第三：手指模式。紀錄在 `openspec/changes/add-finger-mode/`。它只放大介面：一般按鈕、大按鈕、選單項目高度、選單項目間距、縮放控制點、旋轉控制點。每一項自己選小、中、大、特大，預設是大，小是上游原本尺寸。已知像素是一般按鈕、大按鈕、選單項目高度、間距、縮放控制點：
  - 小：32 / 36 / 32 / 1 / 8。
  - 中：36 / 39 / 36 / 4 / 20。
  - 大（預設）：40 / 42 / 40 / 6 / 32。
  - 特大：44 / 44 / 至少 44 / 8 / 44。
- 旋轉控制點是獨立一項，不共用上面的第五欄。它的中、大、特大像素還沒有指定。
- 手指模式開啟且為觸控時，隱藏快捷鍵提示。這不是開關列上的快捷鍵，也不另做一個設定項。
- 三點「更多工具」與設定頁各有一列，版面相同：左手指圖示（沒有勾選）、中間只有「手指模式」、右邊是 Switch 或「開」「關」。沒有快捷鍵、副標或說明。
- 畫布手勢不在這兩份變更裡，維持上游。開關是否仍寫入 `penMode`、放大是否只在觸控時生效，寫在 `add-finger-mode` 的 Open questions，這裡不先決定。

先審查並同意架構。同意之前不寫功能程式，也不改 `packages/` 或 `excalidraw-app/`。設定頁與手指模式的 OpenSpec 是那兩項的用語。多頁 slide 見上方第二優先。其中的校正（返回按鈕、合併頁、各項尺寸、開關列版面、關於、語系鍵）還沒有寫進應用程式。同意之後，PoC 放在 `poc/<name>/`，分支用 `poc/<name>`，各自套件與依賴，不進根目錄 Yarn workspaces。tester 在這個 fork 驗證並開 issue。不直接改 `master`。

架構同意後要寫的 OpenSpec 提案：

- 建立完整的 iPad 風格設定頁（見上方第一優先）。
- 多頁 slide（目標第 2 項，見 `openspec/changes/add-multipage-slides/`）。
- 手指模式（見上方第三優先）。各項尺寸在設定頁、主題與語系下面。每一項自己的四段，預設是大，像素見上方。
- Apple Pencil 的壓力與傾斜，以及 Excalidraw 本身必要的 iPad 調整。操作以觸控與 Apple Pencil 為先，手指同屬 iPad 優先的輸入。
- 動畫 PoC。不做逐格動畫。關鍵影格留在底層、不露出來。路徑用 A–B–C 點，移動、縮放、旋轉自動補間；折線再平滑成曲線。拖曳錄製把手勢簡化成動畫路徑。預設動作只給簡單選項，例如 Zoom In、Slide In／Slide Out。PoC 遵守同一套簡單原則，只用 Apple Pencil 與手指。
- 檔案儲存兩層。Tier 1 是瀏覽器／PWA 的本地儲存（IndexedDB 或 localStorage），編輯求快。Tier 2 是登入 Google 帳號後，用 Google Drive API 存到 Google Drive，讓 iPad 與桌面讀同一份。email 或 zip 匯出是可選，不是必要。iPad 上可用 Web Share API 把打包檔分享到 Google Drive 或其他 app。檔案瀏覽器的順序見下方：先 2a 本地，再 2b Google Drive。
- Beta 唯讀檢視器的範圍。可顯示圖層、時間軸、關鍵影格，以及每個關鍵影格的屬性。不能編輯。Beta 可切到類似 Flash 的時間軸，用來對稿；它看起來像 Flash 是因為它是對稿工具，Flash 本身也把複雜度藏起來不給一般使用者。正式版隱藏並移除這個檢視。

若要研究其他軟體（包含 Excalidraw+），遵守 REA 使用規範：可以觀察與理解，不可以抽出專有程式或素材來用；學到的做法必須自己重寫。每次 REA 工作階段寫進 `journal/`。不確定就停下來問。

在 iPad 上切換 GitHub 帳號、以便審查：GitHub Mobile 自 2023 年 8 月起可同時登入多個帳號。長按底部 Profile 分頁打開帳號切換器，再點要使用的帳號。新增帳號可從同一個切換器，或從 Profile > Settings > Accounts／Manage Accounts。登出是在該帳號上向左滑，再點 Sign out。來源：[GitHub Mobile](https://docs.github.com/en/get-started/using-github/github-mobile)。

## 長期

底層保留 Flash 等級的進階能力。操作介面只露出約 5 個基本選項（觸控與 Apple Pencil）。這是參考值，不是固定數量。沒有進階選單，也沒有進階 UI 控制。

進階功能的唯一入口是 AI，用自然語言，可以打字或用語音。AI 產生動作呼叫腳本（action-calling scripts），再記成時間軸與關鍵影格。

投影片借鏡 PowerPoint 的跨頁補間（類似 Smart Animate），不借鏡 Flash 的場景硬切。Flash 不能在場景之間補間，PowerPoint 可以。每一頁是一個大的關鍵影格，頁與頁之間可以補間。

iPad 與桌面同步用於線上教學：iPad 當白板，筆電分享螢幕。

瀏覽器內的 AI 模型留待評估，今天沒有評估也沒有實作。討論中的選項是 Gemma 2B 或 1B、Phi-3 mini、Llama 3.2 1B。當時的體積與能力說法要在評估時核對。課堂上以後可能的方向是語音轉文字、投影片摘要、產生動畫路徑的說明。

正式版移除 beta 的唯讀時間軸檢視，以及那個類似 Flash、只用於對稿的切換。

第二階段是檔案瀏覽器／工作區，尚未實作。先本地，後 Google Drive。紀錄在 `openspec/changes/add-local-storage-limits/`：

- 2a 先做本地儲存。上限同時是最多 5 個檔案，以及所有檔案合計最多 20 頁。
- 兩個上限一起生效。例如 5 個檔各 4 頁、2 個檔各 10 頁、1 個檔 20 頁都可以；第 6 個檔不行，第 21 頁也不行。
- 2a 達到上限時（例如新建檔案或新增一頁），提示刪除檔案或頁面，或匯出成檔案（例如下載 `.excalidraw`）。此時還沒有 Google Drive。
- 2b 在 2a 之後才接上 Google Drive。檔案存進本地之後提供「移到 Google Drive」。這是先本地、後 Drive 的標準流程：檔案移到 Google Drive，移除本地複本，並釋出它佔用的檔案名額與頁數。
- 2b 達到上限時，提示在刪除之外提供「移到 Google Drive」。上限仍是 5 個檔與合計 20 頁。2a 沒有這個選項。
- 待確認：若用畫框（frame）當投影片，什麼算一頁；既有資料已經超過上限時怎麼處理；是否只有上傳確認成功才移除本地複本；離線時「移到 Google Drive」如何處理。
