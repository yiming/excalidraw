## 短期

先審查並同意架構。同意之前，architect 只提出架構；recorder 不開功能變更；implementer 不寫 PoC，也不改 `packages/` 或 `excalidraw-app/`。同意之後才用 OpenSpec 建變更，PoC 放在 `poc/<name>/`，分支用 `poc/<name>`，各自套件與依賴，不進根目錄 Yarn workspaces。tester 在這個 fork 驗證並開 issue。不直接改 `master`。

架構同意後要寫的 OpenSpec 提案：

- Apple Pencil 的壓力與傾斜，以及 Excalidraw 本身必要的 iPad 調整。操作以觸控與 Apple Pencil 為先，手指同屬 iPad 優先的輸入。
- 動畫 PoC。不做逐格動畫。關鍵影格留在底層、不露出來。路徑用 A–B–C 點，移動、縮放、旋轉自動補間；折線再平滑成曲線。拖曳錄製把手勢簡化成動畫路徑。預設動作只給簡單選項，例如 Zoom In、Slide In／Slide Out。PoC 遵守同一套簡單原則，只用 Apple Pencil 與手指。
- 檔案儲存兩層。Tier 1 是瀏覽器／PWA 的本地儲存（IndexedDB 或 localStorage），編輯求快。Tier 2 是登入 Google 帳號後，用 Google Drive API 存到 Google Drive，讓 iPad 與桌面讀同一份。email 或 zip 匯出是可選，不是必要。iPad 上可用 Web Share API 把打包檔分享到 Google Drive 或其他 app。
- Beta 唯讀檢視器的範圍。可顯示圖層、時間軸、關鍵影格，以及每個關鍵影格的屬性。不能編輯。Beta 可切到類似 Flash 的時間軸，用來對稿；它看起來像 Flash 是因為它是對稿工具，Flash 本身也把複雜度藏起來不給一般使用者。正式版隱藏並移除這個檢視。

若要研究其他軟體（包含 Excalidraw+），遵守 REA 使用規範：可以觀察與理解，不可以抽出專有程式或素材來用；學到的做法必須自己重寫。每次 REA 工作階段寫進 `journal/`。不確定就停下來問。

在 iPad 上切換 GitHub 帳號、以便審查：GitHub Mobile 自 2023 年 8 月起可同時登入多個帳號。長按底部 Profile 分頁打開帳號切換器，再點要使用的帳號。新增帳號可從同一個切換器，或從 Profile > Settings > Accounts／Manage Accounts。登出是在該帳號上向左滑，再點 Sign out。來源：[GitHub Mobile](https://docs.github.com/en/get-started/using-github/github-mobile)。

待確認：

- 操作介面的基本選項個數。整理稿是 3 到 5 個；本計畫按大約 5 個寫。精確數字等架構同意時定案。
- 名為 `schedule` 的 GitHub repo 要不要改名。我們看不到它在 `yiming` 這個帳號下，可能在另一個 GitHub 帳號，或是尚未授權的私人 repo。建議新名是 `scholario-exp`（Scholario Experiment）。尚未改名，等使用者確認。

## 長期

底層保留 Flash 等級的進階能力。操作介面只露出大約 5 個基本選項，給觸控與 Apple Pencil。沒有進階選單，也沒有進階 UI 控制。

進階功能的唯一入口是 AI，用自然語言，可以打字或用語音。AI 產生動作呼叫腳本（action-calling scripts），再記成時間軸與關鍵影格。

投影片借鏡 PowerPoint 的跨頁補間（類似 Smart Animate），不借鏡 Flash 的場景硬切。Flash 不能在場景之間補間，PowerPoint 可以。每一頁是一個大的關鍵影格，頁與頁之間可以補間。

iPad 與桌面同步用於線上教學：iPad 當白板，筆電分享螢幕。

瀏覽器內的 AI 模型留待評估，今天沒有評估也沒有實作。討論中的選項是 Gemma 2B 或 1B、Phi-3 mini、Llama 3.2 1B。當時的體積與能力說法要在評估時核對。課堂上以後可能的方向是語音轉文字、投影片摘要、產生動畫路徑的說明。

正式版移除 beta 的唯讀時間軸檢視，以及那個類似 Flash、只用於對稿的切換。
