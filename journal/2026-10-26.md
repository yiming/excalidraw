## Decisions

- 預設分支是 `master`。不直接在上面改，用分支與 PR 整合。環境分支 `ipad-features` 從下述已部署 Pages 的 `master` 拉出。
- `docs/` 放這個 fork 的討論備忘。根目錄原本沒有 `docs/`；上游文件在 `dev-docs/`，維持不動。`journal/` 放有日期的開發日記。
- 每個正式變更用 OpenSpec 記在 `openspec/`。
- `poc/` 放獨立小專案，各自套件與依賴，不進根目錄 Yarn workspaces。分支名 `poc/<name>`。證明可行之後才考慮合回主線。
- `.claude/agents/` 的四個角色是 architect（架構）、implementer（實作）、tester（驗證與開 issue）、recorder（OpenSpec）。`commands/`、`skills/`、`hooks/` 保留以後使用。
- GitHub Actions 範本只在推送到 `poc/**` 時跑 PoC 測試。Pages 重新部署維持由既有的 `Deploy GitHub Pages` 在 `master` 上執行；範本裡的觸發保持停用，避免同一次推送排出第二個正式部署。
- 架構同意之前不寫功能程式。

## File storage

檔案儲存用兩層。

- Tier 1：檔案放在瀏覽器／PWA 的本地儲存（IndexedDB 或 localStorage），編輯時先求快。
- Tier 2：使用者以 Google 帳號登入後，可以透過 Google Drive API 把檔案直接存到 Google Drive，讓 iPad 與桌面都能讀到同一份。
- 以 email 或 zip 匯出是可選的加分項，不是必要功能。
- 在 iPad 上可以用 Web Share API，把打包好的檔案分享到 Google Drive 或其他 app。

## Design principles

- 所有操作必須簡單。這是課堂白板，操作不可以變複雜。
- 必須能在 iPad 上用 Apple Pencil 與手指操作。桌面也要能用，但 iPad 體驗優先。
- 互動保持少：直接畫、簡單手勢、選項少。
- 動畫 PoC 遵守同一套簡單原則，只用 Apple Pencil 與手指。
- Excalidraw 本身要做必要的 iPad 調整。
